# MAX Network — NeuroPulse

Локальная FastAPI-панель: каналы MAX, RSS/Atom, черновики, изображения и короткие русские посты через Ollama `qwen2.5:3b`. Публикация осуществляется только по кнопке через `https://platform-api.max.ru`. Автопубликация отключена в коде, включая старые записи с `autopublish=1`.

## Запуск на Mac

1. Установите Python 3.12 (проверенная версия окружения — 3.12.14): `brew install python@3.12`, либо установщиком с python.org.
2. Установите Ollama с официального сайта ollama.com, запустите приложение Ollama. В терминале загрузите модель:

   ```bash
   ollama pull qwen2.5:3b
   ollama list
   ```

   Если фоновый сервер не запущен, выполните `ollama serve` в отдельном терминале. Загрузка модели требует интернета и нескольких гигабайт диска; дальнейшая генерация локальная.
3. В папку проекта рядом с `app.py` поместите **свои прежние** `.env` и `network.db`. Не заменяйте старую базу пустой. Сначала остановите старую копию приложения. Если базы нет, будет создана новая; прежние данные из неё восстановить невозможно.
4. Запустите:

   ```bash
   cd /путь/к/MAX-Network
   chmod +x start.command
   ./start.command
   ```

5. Откройте `http://127.0.0.1:8000`. Логин — `admin`, пароль — существующий `ADMIN_PASSWORD` из вашего `.env`.

При первом запуске создаётся `.venv`; зависимости устанавливаются из проверенного `requirements.lock.txt` (включая pytest для проверок). Скрипт требует Python 3.12+. Старую `.venv` от Python 3.9 при необходимости переименуйте и запустите скрипт снова. Перед каждым стартом скрипт создаёт согласованную резервную копию SQLite в `backups/`. Миграции добавляют поля без удаления существующих записей.

## Работа в панели

- Добавьте любое количество каналов, задайте числовой Chat ID. Бот с вашим `MAX_TOKEN` должен иметь право отправки сообщений в канал. Панель управляет локальными настройками существующих каналов; не создаёт каналы в самом MAX.
- Назначьте каждому каналу RSS/Atom URL (публичный HTTPS). Источники отображаются сразу после добавления. Дубли одного URL в одном канале запрещены.
- Включённые каналы собираются раз в 3 часа, пока запущен сервер. Кнопка «Собрать сейчас» собирает источники всех каналов, включая отключённые, но не публикует ничего. На один источник обрабатываются первые 10 записей. Прогресс показывает этап, источники, добавленные записи, дубли, фильтрацию и ошибки. Не запускайте несколько серверов/worker-процессов для одной базы.
- Фильтры задаются отдельно для канала, через запятую: достаточно одного интересующего слова, исключающее слово блокирует запись. Сравнение — подстрока без учёта регистра. По умолчанию фильтры пустые, чтобы не скрывать новости без вашего выбора.
- Дубли определяются внутри канала по URL без рекламных `utm_*`, `fbclid`, `gclid`, `yclid` и фрагмента. Это не семантическое сравнение текстов между разными сайтами.
- Из RSS извлекаются media/enclosure/HTML-изображения. Относительные ссылки разрешаются относительно записи. Предпросмотр загружается браузером с сайта источника; доступность изображения и права использования нужно проверить самостоятельно.
- Сохраните текст, изображение и подтверждение прав, затем нажмите «Опубликовать в MAX» и подтвердите действие. Изменения несохранённого черновика отправить нельзя. Уже опубликованная запись повторно не отправляется.
- При недоступной Ollama исходный материал сохраняется с предупреждением; публикация такого текста блокируется. Запустите Ollama и нажмите «Перегенерировать», либо вручную отредактируйте и проверьте текст.
- Удалённые черновики скрываются, но их отпечатки сохраняются для защиты от повторного сбора. Канал с источниками или историей нельзя удалить — его можно отключить.
- При сетевой ошибке публикации проверьте сам канал перед повтором: MAX мог принять запрос, даже если ответ не дошёл.

## Конфигурация

Существующий `.env` не изменяется. Нужны `ADMIN_PASSWORD` и `MAX_TOKEN`. Поддерживаются `MAX_CHAT_ID_1`, `MAX_CHAT_ID_2` для первоначального заполнения новой базы; Chat ID существующих каналов редактируются в панели.

Дополнительные переменные: `OLLAMA_MODEL=qwen2.5:3b`, `OLLAMA_URL=http://127.0.0.1:11434`, `MAX_API_BASE=https://platform-api.max.ru`, `NETWORK_DB_PATH` (другая база, удобно для тестов). `.env` читается относительно `app.py`, а не рабочей папки.

VPN или иностранные платные API приложению не нужны. Доступность конкретных RSS, сайта загрузки модели и MAX зависит от вашей сети и источников; доступ из России здесь не проверялся. Ollama работает локально. Панель слушает только loopback: не открывайте её в интернет, HTTP Basic рассчитан на локальное использование.

Никогда не добавляйте `.env`, базы и резервные копии в Git. Автопубликация по расписанию — отдельный будущий этап после проверки ручной отправки.

## Проверки

```bash
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python -m pytest -q
```

Тесты используют временную SQLite-базу и подменяют ответы RSS, Ollama и MAX. Они не публикуют сообщения и не изменяют рабочую базу. Реальную генерацию и публикацию нужно проверить на Mac с запущенной моделью и правами бота.
