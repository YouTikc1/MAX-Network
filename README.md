# MAX Network · локальная редакция NeuroPulse

Панель для RSS/Atom → редактора Ollama → коротких русскоязычных постов → каналов MAX. Python **3.12+**, `qwen2.5:3b`, API `https://platform-api.max.ru`. Интерфейс и шрифты не используют внешние CDN.

## Обновить существующую установку на Mac

Остановите сервер через **Ctrl+C** в его терминале, затем:

```bash
cd ~/Downloads/MAX-Network-new
git pull --ff-only
./start.command
```

Откройте `http://127.0.0.1:8000` и обновите страницу **⌘R**. Если браузер показывает старое оформление, используйте **⌥⌘R**. Старые `.env`, источники, каналы и черновики сохраняются. Перед миграцией скрипт создаёт согласованную резервную копию SQLite в `backups/`. Обновление добавляет поля и таблицу журнала; базы и `.env` не хранятся в Git.

## Первый запуск на Mac

1. Установите Python 3.12+ с [python.org](https://www.python.org/downloads/macos/), macOS universal2 installer подходит для Intel и Apple Silicon. Для Python 3.12 после установки запустите `/Applications/Python 3.12/Install Certificates.command`. Скрипт запуска распознаёт Python 3.12 из официального установщика даже без изменения PATH. При рабочем Homebrew можно использовать `brew install python@3.12`.
2. Установите и запустите [Ollama](https://ollama.com), затем:

   ```bash
   ollama pull qwen2.5:3b
   ```

3. Скачайте проект:

   ```bash
   cd ~/Downloads
   git clone https://github.com/YouTikc1/MAX-Network.git MAX-Network-new
   cd MAX-Network-new
   ```

4. Поместите свои прежние `.env` и `network.db` рядом с `app.py`. В Finder скрытые файлы показывает **⌘⇧.** Не заменяйте старую базу пустой; сначала остановите старое приложение. Если базы нет, создаётся новая.
5. Выполните:

   ```bash
   chmod +x start.command
   ./start.command
   ```

Откройте `http://127.0.0.1:8000`. Логин `admin`, пароль — существующий `ADMIN_PASSWORD` из `.env`. Терминал оставьте открытым. Для автономной работы без засыпания можно вместо обычного старта использовать `caffeinate -i ./start.command` (пока крышка открыта). Выключенный или спящий Mac не собирает и не публикует новости.

## Отбор новостей через Ollama

Каждому каналу задаётся редакционное задание, например: «Важные релизы моделей и продуктов ИИ, исследования с результатами. Без рекламы, курсов, руководств и личных блогов». Дополнительные ключевые и исключающие слова необязательны.

Модель возвращает структурированное решение: публиковать ли материал, оценку **0–100**, причину и короткий текст **100–750 символов** от третьего лица. Порог по умолчанию — **75**. Ссылку добавляет приложение. Проверяется формат результата, длина, русский язык и распространённые вступления от лица автора. Это проверка пригодности, а не независимый фактчекинг: небольшая модель может ошибаться, качество зависит от содержания RSS.

- **Готовые** — модель рекомендует публикацию, оценка не ниже порога.
- **На проверке** — старый/изменённый черновик либо модель не ответила корректно. Автоматически не отправляется.
- **Отклонённые** — реклама, низкая оценка, неподходящая тема или RSS-запись с датой старше 72 часов. Причина видна на карточке. Можно запустить оценку повторно.
- **Опубликованные** — подтверждённые отправки с MAX message ID.

Существующие черновики после обновления не получают одобрение автоматически: в очереди нажмите **«Оценить старые черновики»** (до 30 за проход). Фоновый сбор раз в 30 минут обрабатывает первые 10 записей каждой ленты включённых каналов и затем повторяет оценку ожидающих материалов этих каналов. Ошибка Ollama не превращается в разрешение на публикацию. На Intel Mac оценка каждой новости может занимать минуты; окно модели — 8192 токена, запрос ограничен 240 секундами.

## Включить автопостинг

При первом обновлении автопостинг остаётся выключенным, даже если в старой базе был установлен флаг автоматической отправки.

1. Откройте **«Каналы и автопостинг → Настроить»**. Укажите числовой Chat ID, редакционное задание и включите канал. Бот с вашим `MAX_TOKEN` должен иметь права публикации.
2. В очереди проверьте один пост и отправьте его вручную. Если изображение не ваше — удалите URL; если у вас есть право использования — подтвердите его и сохраните.
3. После успешной ручной отправки снова откройте настройки канала. Включите **«Автопубликацию выбранных ИИ новостей»** и сохраните расписание.

По умолчанию: **раз в 60 минут, максимум 6 постов в день, 09:00–22:00 по Москве**. Можно изменить интервал (15–1440 минут), дневной лимит (1–24), часы и часовой пояс. Начало окна должно быть раньше конца, ночные окна через полночь задаются как дневной диапазон в подходящем часовом поясе. Первая автоматическая отправка — не раньше заданного интервала после включения, только в рабочем окне и при наличии подходящего поста. Расписание проверяется раз в минуту. После сна/перезапуска нет залповой отправки пропущенных слотов.

Автопостинг выбирает пост с наибольшей оценкой. Отправляется только неизменённый текст с одобрением не старше 24 часов, черновик не старше 72 часов и доступной свежестью источника (когда дата есть в RSS). Сначала применяется проверка дублей по нормализованному URL; перед автоматической отправкой также сравниваются заголовки с опубликованными/неопределёнными отправками в этом канале. Это не полноценное семантическое сравнение всех сайтов.

Картинки без подтверждённых прав **не прикрепляются автоматически**: публикация отправляется только с текстом. Одобренные изображения прикрепляются через MAX API. Дневной лимит и минимальный интервал учитывают также ручные публикации. Смена Chat ID требует новой ручной проверки; смена темы/фильтров/порога сбрасывает прежние оценки черновиков.

### Ошибки и пауза

- Кнопка **«Приостановить автопостинг»** запрещает новые автоматические отправки во всех каналах. Уже отправленный запрос нельзя отозвать этой кнопкой.
- Ошибка автоматической отправки отключает автопостинг канала и появляется в журнале.
- При таймауте, ошибке сервера MAX или прерванной отправке результат может быть неизвестен. Повторный запрос не отправляется: запись помечается **«Требует сверки»**. Откройте канал MAX, найдите сообщение и подтвердите в панели, было ли оно опубликовано. Лишь после сверки можно включить расписание заново.
- При однозначном HTTP 4xx черновик остаётся с ошибкой; исправьте настройки и проверьте отправку.
- Приложение запускается **одним процессом / одним worker** для одной базы.

## Данные и конфигурация

Обязательные переменные существующего `.env`: `ADMIN_PASSWORD`, `MAX_TOKEN`. Дополнительные: `OLLAMA_MODEL=qwen2.5:3b`, `OLLAMA_URL=http://127.0.0.1:11434`, `MAX_API_BASE=https://platform-api.max.ru`, `NETWORK_DB_PATH` для отдельной тестовой базы. `MAX_CHAT_ID_1/2` используются только при первоначальном создании каналов в новой базе. `.env` читается рядом с `app.py`.

Удаление черновика скрывает запись и сохраняет отпечаток для защиты от дублей. Канал с источниками или историей нельзя удалить — отключите его. RSS принимает публичные HTTPS-адреса, изображения извлекаются из media/enclosures/HTML. Наличие изображения в RSS не подтверждает права использования.

Ollama работает локально, иностранные платные API или VPN приложению не нужны. Доступность конкретного RSS и MAX зависит от вашей сети. Порт 8000 слушает только `127.0.0.1`; панель рассчитана на локальное использование.

## Проверки

```bash
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python -m pytest -q
```

Проверяются миграции без потери записей, RSS, структурированный отбор, недоступная/некорректная Ollama, сброс одобрения при редактировании, ручная проверка MAX, расписание, часовой пояс, лимиты, дубли, конкурентные отправки, неизвестный результат и пауза. Тесты используют временные базы и подменённые HTTP-ответы — реальных сообщений не отправляют. Реальное качество qwen2.5:3b и права вашего бота проверяются на Mac.
